# 设计系统

> 这份文件是**硬约束**。外部依据与数值标准见 `DESIGN-REFERENCE.md`（含落地检查表）。
>所有页面、所有组件都按它来，违反就是 bug。

## 原则（用户明确提出的）

1. **暖色为主，不用纯黑。** 明色走米纸暖调。深色两种都可以：
   - 暖褐（`#16120E`）—— 纸感、长时间阅读不刺眼
   - 深蓝（`#0E1621`）—— 冷调夜景
   **共同底线：不许 `#000`，不许纯灰。**
2. **不要句子。** 界面文案只用「名词 / 数字」。不写解释性副标题。
   - ❌ 体检通过且在启用　❌ 已禁用，未判定要冻结　❌ 占用 105 MB
3. **去 AI 味。** 不写「A / B」并列短语，不写四字套话，不写「原型·用你真实数据驱动」这种自述。
4. **少用标签胶囊。** 状态优先用「颜色 + 位置 + 形状」表达，而不是带文字的徽章。
5. **匠心来自克制。** 留白、字阶、对齐、颜色的用量。不靠装饰、不靠动效堆砌。
6. **一致性。** 所有页面共用同一套 token。切到任何一页都不能像换了个 app。

## 排版

- 字族：UI = 思源黑体/更纱黑体；正文（阅读页）= 霞鹜文楷 / 思源宋体。原型先用系统字。
- **只保留 3 档字重**：400 / 500 / 600。禁止满屏 bold。
- 字号阶：`32 / 22 / 17 / 15 / 13 / 11`。不额外发明尺寸。
- 数字一律 `font-variant-numeric: tabular-nums`，列表里数字要能对齐。
- 行高：标题 1.25，正文 1.6，列表 1.4。

| 已禁用，未判定要冻结 | （删掉） |

| URL 无 host | 无地址 |

| 点击行 = 多选 | （删掉，靠操作条自解释） |

**规则**：一个界面里，每一行文字都要有存在理由。删掉后不影响理解 → 删。

## 状态表达

不用文字胶囊。用：
- 列表行**左侧 3px 色带** + 右侧状态名（小字、次要色，无底色无边框）
- 统计卡用**顶部 2px 色带** + 数字本身着色

## 动效

- 缓动：`cubic-bezier(.2,.9,.25,1)`（近 spring，有回弹感）
- 时长：页面/抽屉入场 300~340ms；悬停/按下微交互 160~200ms
- 只对 `transform` 和 `opacity` 做动画，不动 layout 属性

## 无封面时的默认封面（2026-10-05 定，依据外部书封设计资料）

来源：bookcoverslab「Book Cover Typography: 7 Rules」、coverfairy「title/subtitle/author hierarchy」。

1. **只有一个阅读顺序。** 书名最大最强 → 副标题/系列 → 作者明显更弱。
   三者字号字重接近是最常见的败笔；本轮把「封面上的书名」和「封面下的小标题」重复出现这件事列为待决。
2. **不许靠描边、发光、阴影救可读性。** 分隔来自构图本身：留白、平静色块、克制的底色。
   描边会「藏住弱构图而不解决它」。默认封面底是平色，本来就不需要描边 —— 已去掉。
3. **断行按视觉重量均衡，不留孤字。** 长中文书名不能傻填满一行（会甩出「对)」这种孤字）；
   收尾标点（，。）》」』…）不能出现在行首 —— 已实现 `balancedTitleLines()` 自己做断行。
4. **展示级字号行距收紧**：书封标题 1.1~1.2，正文才用 1.4~1.6。现在用 1.18。
5. **缩略图与灰度测试**：小尺寸下书名的块形要仍成立；灰度下明度对比要够。
   实测默认封面书名对比度 6.28:1（WCAG 大字号门槛 3.0）。
6. **最多两个字族**：一个字族出性格（书名），一个安静的做辅助（作者）。
7. **有书名时不再画通用书本图标**：两者抢焦点。图标只在没有书名时当占位。

### 默认封面的最终口径（2026-10-05 用户指定）

> 「每个封面你都用个**米粉色的底子**，中间画个**山水**（作为壁纸），然后用比较大一点的
>  **手写楷体/行体**写上书名，书名下来个**红章**，印个作者（**没作者两个都不要**）」

落成（`CoilBookCover.kt`）：
- 底：米粉 `#F7EEE6`（夜间 `#221D19`，山水反相成浅墨，否则深墨压深底等于没有）
- 纹：`assets/coverArt/kazusa-shanshui.png`（程序生成：低频平滑脊线 + 每层墨色渐隐 + 柔雾 + 淡日 + 水面横纹）
- 书名：霞鹜文楷（外挂字体目录，取不到回退系统衬线），字号按长度自适应，自己均衡断行
- 印章：朱砂 `#B03A2A` 圆角方章，白字刻作者（1~2 字竖排、3~4 字两行）
- **没有作者就不画印章、也不画作者**（用户明确）
- 纸纹生成脚本：`scripts/gen-cover-art.py`（山水）
